## General Usage

The Multipurpose Launcher is divided into several sections:
- Input sections at the top for launching specific types of IDs
- Tool cards organized by category below
- Search functionality to quickly find tools

Each section is designed to handle specific types of IDs and direct you to the appropriate tools.

## Case IDs Section

### How to use:
1. Enter one or more Case IDs in the text area (one per line)
2. Select the appropriate region (NA or EU)
3. Click the LAUNCH button

### What happens:
Each Case ID will open in Paragon with the correct domain based on the selected region. This allows you to quickly access multiple cases without having to manually navigate to each one.

## Seller ID / Order ID Section

### How to use:
1. Enter one or more Seller IDs or Order IDs in the text area (one per line)
2. Select the appropriate region (NA or EU)
3. Select the tool (Paragon or Brand Registry)
4. Click the LAUNCH button

### What happens:
The launcher will automatically detect the type of ID and open the appropriate tool:

- **Order IDs with hyphens** (e.g., 112-8419001-7170665): Opens in Seller Central with the direct order view
- **Order IDs starting with 'A'**: Opens in Seller Central with the order details view
- **Seller IDs with Paragon selected**: Opens in Paragon search with the correct domain based on region
- **Seller IDs with Brand Registry selected**: Opens in Brand Registry search

This intelligent routing saves time by automatically directing you to the right tool based on the ID format.

## ASINs Section

### How to use:
1. Enter one or more ASINs in the text area (one per line)
2. Select the region (NA, EU, FE, or Other)
3. Select the marketplace (automatically populated based on region)
4. Select the tool from the dropdown (CP-Central, CSI-TimeMachine, CSI, Media Central)
5. Click the LAUNCH button

Alternatively, you can use the checkboxes to open ASINs in multiple tools at once:
1. Check one or more tool checkboxes
2. Click the LAUNCH SELECTED button

### What happens:
Each ASIN will open in the selected tool(s) with the appropriate parameters. This allows you to quickly check multiple ASINs across different tools without having to manually enter each one.

If no checkboxes are selected when using the LAUNCH SELECTED button, it will use the tool selected in the dropdown.

## Search for SIM's Section

### How to use:
1. Enter a Seller ID in the text area
2. Click the LAUNCH button

### What happens:
The Seller ID will open in the SIM search, showing all SIMs (opened or resolved) for the given Seller ID, sorted by the last updated conversation date in descending order. This helps you quickly find relevant SIMs for a particular seller.

## Tool Cards

The tool cards are organized into categories:
- **Investigation Tools:** Tools for case management and investigation
- **Research & Verification Tools:** Tools for research and verification
- **IP & Brand Protection:** Tools for intellectual property and brand protection

### How to use:
1. Click on any tool card to open the corresponding tool in a new tab

You can also use the search box at the top to quickly find a specific tool.

## Search Functionality

### How to use:
1. Type in the search box at the top of the page

### What happens:
As you type, the tool will filter the tool cards to show only those that match your search term. The search looks at both the tool name and description.

Categories with no matching tools will be hidden, making it easier to find what you're looking for.

## Detailed Tool Information

### Investigation Tools

#### Paragon
**Purpose:** Primary case management system for handling customer and seller issues.

**When to use:** When you need to view case details, update cases, or search for cases by various parameters.

**Key features:** Case viewing, case updating, case search, case history tracking.

#### CSI (Catalog Simple Investigation)
**Purpose:** Tool for investigating product catalog data and issues.

**When to use:** When you need to check product details, variations, offers, or catalog issues.

**Key features:** Product data viewing, offer information, variation relationships, catalog health metrics.

#### TimeMachine
**Purpose:** Tool for viewing historical data about products and listings.

**When to use:** When you need to check how a product listing has changed over time or investigate past issues.

**Key features:** Historical data viewing, timeline of changes, comparison between dates.

#### Seller Central
**Purpose:** Main portal for sellers to manage their Amazon business.

**When to use:** When you need to view the seller's perspective or check seller-specific information.

**Key features:** Order management, inventory management, performance metrics, seller settings.

#### SIM Search
**Purpose:** Tool for searching and managing Seller Issue Management cases.

**When to use:** When you need to find SIMs related to specific sellers or issues.

**Key features:** SIM search, SIM creation, SIM management, issue tracking.

#### Media Central
**Purpose:** Repository for product images and media.

**When to use:** When you need to check product images or investigate image-related issues.

**Key features:** Image viewing, image history, image metadata.

#### Darwin
**Purpose:** Tool for investigating duplicate ASIN issues.

**When to use:** When you need to compare two or more ASINs to determine if they are duplicates.

**Key features:** Side-by-side ASIN comparison, attribute comparison, duplicate detection.

#### CP Central
**Purpose:** Tool for investigating restricted product issues.

**When to use:** When you need to check if a product violates policies or understand why a product is restricted.

**Key features:** Policy violation checking, keyword detection, restriction reason identification.

#### Nemo Tool
**Purpose:** Tool for accessing specific task IDs in Paragon.

**When to use:** When you need secure access to case data for audits or special projects.

**Key features:** Secure access, task ID lookup, controlled data access.

### Research & Verification Tools

#### WhoIs
**Purpose:** Tool for looking up domain registration information.

**When to use:** When you need to verify domain ownership or check domain registration details.

**Key features:** Domain lookup, registration information, contact details.

#### What is my IP
**Purpose:** Tool for IP address lookup and information.

**When to use:** When you need to check IP address details or location.

**Key features:** IP lookup, geolocation, ISP information.

#### Amazon Translate
**Purpose:** Translation service for multiple languages.

**When to use:** When you need to translate text from one language to another.

**Key features:** Text translation, language detection, batch translation.

#### Global Transfer Guide
**Purpose:** Guide for all transfer queues across Amazon.

**When to use:** When you need to find the correct queue for transferring a case or issue.

**Key features:** Queue listings, transfer procedures, contact information.

### IP & Brand Protection

#### EUIPO
**Purpose:** European Union Intellectual Property Office website.

**When to use:** When you need to verify EU trademarks or intellectual property.

**Key features:** Trademark search, design search, IP guidelines.

#### WIPO
**Purpose:** World Intellectual Property Organization database.

**When to use:** When you need to check international trademark registrations.

**Key features:** Global brand database, international registrations, Madrid system.

#### USPTO
**Purpose:** United States Patent and Trademark Office website.

**When to use:** When you need to verify US trademarks or patents.

**Key features:** Trademark search, patent search, TESS database.

#### IP India
**Purpose:** Indian Intellectual Property Office website.

**When to use:** When you need to verify Indian trademarks or intellectual property.

**Key features:** Trademark search, patent search, design search.

#### IP Tracker
**Purpose:** Tool for tracking IP addresses and their information.

**When to use:** When you need detailed information about an IP address.

**Key features:** IP lookup, geolocation, network information.

#### Brand Registry
**Purpose:** Amazon's brand protection program and tool.

**When to use:** When you need to verify brand ownership or handle brand protection issues.

**Key features:** Brand verification, infringement reporting, brand protection tools.
